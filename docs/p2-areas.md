# P2 · 区域元素适配度

> 由 `python3 -m tools.p2_areas` 生成。**这是所有「区域平均系数」数字的唯一来源**，
> 文档里引用这些数字时必须指向本文件，不要再手算。

**本次规则：`strict`** —— `passive_*_pierce` **不能破免疫**（1.13 只有 Conviction / Lower Resist 可以，且对免疫怪按 1/5 生效）。这是默认规则，也是结论所依赖的规则。

计算口径：

- 区域来自 `levels.txt`（只算挂了怪的区域），怪物抗性来自 `MonStats.txt` 的地狱列
- 单点倍率 = `(1 + 伤害%) × (1 - 最终抗性/100)`，抗性下限 −100%
- 区域平均系数 = 该区域内所有怪物单点倍率的平均；**0 表示进去完全打不动**

## 结论怎么用

- **`strict` 规则下，穿透类改动永远无法把归零区域变成非零** —— 所以「消除归零区域」
  这句话只有在 `breaking` 假设下才成立，不能拿来当改动的理由。
- 穿透的真实价值在 **50~99% 抗性**那一段：把 0.38 拉回 1.05 是实的，
  把「打不动」变「能打」是虚的（免疫不动）。
- 想解决归零区域，唯一的杠杆是 `Conviction` / `Lower Resist`（技能层）
  或降低怪物抗性（但那是提高/降低难度，属于别的议题）。
