## 整合说明

### 前言

①点击 删除Diablo II注册表.bat—以前玩别的版本，换本版或其他版必备

②点击 去除数据执行保护.bat—右键管理员身份运行—如果是绿色表示正常，红色不正常

③点击PatchD2gfxDll.exe注册，有些情况下可能需要点击同在游戏目下的PatchD2File.exe注册（玩过其他版本，用过大箱子的，点击RestoreD2gfxDll.exe、RestoreD2gfxDll.exe这俩后，再点击③的2个patch注册本游戏目录下的大箱子）

④开始游戏-D2GL高清.bat，即可正常游戏，如果没反应，设置game.exe，右键兼容性改成XP SP2或SP3—这步启动有问题的，看看常见问题，有时需要安装运行库等游戏必备的系统组件。

——如果没反应，D2VidTst.exe兼容性改成xp sp2，并运行进行检测，一般自动选择3d模式，最后bat启动。

——在游戏中，按■■■■Alt+Enter■■■■可全屏

——在游戏中，按■■■■Ctrl+O■■■■调节窗口大小，默认的窗口1068*600比较小，自己选择大小。

⑤游戏产生的垃圾，请点击清除临时文件.bat，进行清理

⑥如果有问题，看看常见问题答疑.docx

⑦如果esc后选择退出游戏时，卡住了，请稍作等待，正常情况是可以退回游戏开始界面。

   调节esc菜单的分辨率的时候，尽量慢些，插件容易崩溃。

   建议亮度调至大概50%，对比度100%或者50%到100%之间，画面更舒服。

注意：本来就是自娱自乐的DIY产品，类似可能还有bug，请大家谅解！

          有空也请多多测试，找出可能的问题，能帮忙修改斧正的话，非常感谢！

## 我们的批注

### 版本来源

「官方数字收藏版 1.12a + 官方 1.13c 升级补丁」→ 核心版本来源可信。
但需用 `game.exe` 的 FileVersion 核实确实是 **1.13c**（1.13d 的 PlugY 版本与偏移都不同）。

### 与本项目「轻度修补」的关系

| 类别 | 条目 | 判断 |
|---|---|---|
| **已是重度改动** | 阿卡拉超级商店卖宝石/符文、boss 永远首杀掉落、掉落超 6 个、无限注魔打孔、暗金绿装属性乱入、16×16 大背包/箱子/盒子、城内传送、取消死亡惩罚、聚气无限 | 改变游戏节奏，与「轻度」是两条路 |
| **QoL（可参考优先级）** | 大箱子、快捷施法、死亡不掉装备、无限回城/辨识、金币上限、书/钥匙上限 500 | 社区痛点排序，可作为我们 P2 的参考权重 |
| **印证原版 bug** | 修复法力燃烧 / 专注 / 三闪 / 魔影斗篷 / 冰封球 | 印证 PLAN §5 的 `[待核实]` 项，说明社区早已确认这些是原版缺陷 |
| **纯表现层** | 仿 D2R UI、彩色词缀/图标/符文、晴圆繁体字体、血蓝条、伤害显示 | 与数值无关，但会改变截图验证的基准 |

### 技术风险

1. `PatchD2gfxDll.exe` / `PatchD2File.exe` 已改 `game.exe` / `D2Gfx.dll`
   → **1.13c 的偏移表不再适用**，P4 代码级补丁路线受限。
2. `D2GL` 换掉渲染器 + `SGD2FreeRes` 高分屏 → 窗口尺寸由 D2GL 控制（`Ctrl+O`），
   截图自动回归要按它的行为适配。
3. 大背包/大箱子/大盒子依赖 `inventory.txt` 与 DLL 格子数一致 → **本项目禁止修改 `inventory.txt`**。
4. 自带 DIY 护身符存档 → **禁止改 `itemstatcost.txt` 的 Save Bits / stat ID**。
5. 字体是繁体晴圆 → 将来做中文文本是 **Big5/950**，不是 GBK/936。
6. 「去除数据执行保护.bat」会动 Windows DEP 设置（VM 内可接受，真机不建议）。

### 待核实（需 `tools/vm_diag.bat` 输出）

- `data\global\excel\*.txt` 是否有散文件 → 决定能否直接 diff 出作者的改动清单
- 三个 MPQ 的体积 → 判断是否被重打包（决定基线可信度）
- `开始游戏-D2GL高清.bat` 的启动参数 → 决定 `-direct -txt` 能否共存
