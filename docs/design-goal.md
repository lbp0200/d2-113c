# 设计目标 v2：让它"像一款游戏"

> **本文取代 [p3-design.md](p3-design.md) 的目标定位。**
> p3-design.md 的 A/B/C 清单仍然有效（是具体改动），但它当时的目标是"轻度修补"，
> 现在是"重做激励结构"。两者不冲突，但边界变了。

---

## 1. 目标变更记录

| | 旧目标（v1） | 新目标（v2） |
|---|---|---|
| 定位 | 轻度修补：只修"玩家再懂也做不到"的地方 | **让游戏像一款游戏**：选择有后果、收益挂钩挑战、没有死内容 |
| C 档负面清单 | 大量"不做"（怕改坏） | 部分解禁：掉落结构、稀有度、难度曲线都可以动 |
| 判据 | "不可解 → 修" | "不构成游戏 → 修" |

**仍然不做的**（这些是硬约束或骨架，动了就不是 D2 了）：

- 技能协同（**硬编码在 Dll**，txt 没有对应列）
- 新增技能 / 技能树 / 物品 / 地图 / 怪物
- UI / AI / 渲染
- 改玩法骨架：职业定位、技能树结构、物品池、区域结构

## 2. "像一款游戏"的四条可验收标准

目标必须能判断，否则改到哪算完都不知道。提议四条：

| # | 标准 | 反例（D2 现状） |
|---|---|---|
| **S1** | **选择有后果**：build 决定你"擅长什么"，不决定你"能不能玩" | 免疫墙：单元素 build 在某些区域**根本不能玩** |
| **S2** | **收益挂钩挑战**：收益与"处理了什么难度"正相关，与"点了多少次"无关 | 开箱子：零战斗，事件密度是打怪的 6 倍 |
| **S3** | **没有死内容**：每个技能 / 佣兵 / 区域至少有一个存在理由 | A3/A5 佣兵：更贵更弱；一批技能伤害/法力只有同职业的 1/20 |
| **S4** | **失败可归因**：打不过是"决策错"，不是"随机数不够好" | 高符文 1/75000 击杀，等于买彩票 |
| **S5** | **刷得值得**：终局之后仍有理由继续，但继续的理由是"打法不同"而不是"投币次数更多" | 毕业后的动力全靠老虎机（1/75000 的尾巴），换条路刷没有意义 |

**这五条就是验收标准。** 每条改动都要说清它推进哪一条。

---

## 2.5 关于"毕业了也会继续刷"（重要澄清）

D2 玩家即便装备毕业也会一直刷。**这不是缺陷，是这款游戏的设计支柱**，所以：

- **P1（毕业时间不变）是对的**：目标不是让人更快毕业。
- **目标不是"减少刷"，而是"让刷的过程本身像游戏"**。

但"刷"有两种，价值完全不同：

| | 数值刷（老虎机） | 内容刷（有目标的推进） |
|---|---|---|
| 驱动 | 变量比率强化：再来一次可能就出 | 明确的下一个目标 |
| D2 现状 | **主力**（HR、完美词缀、99 级） | 薄弱（社区自创的 Holy Grail：集齐全暗金/绿装） |
| 换路线有区别吗 | 没有（只看投币次数） | 有（不同目标在不同地方） |
| 能不能靠 txt 改 | 只能改掉率 | **能**：产出分化、保底、挑战专属产出 |

D2 的长期动力几乎全压在左边那一列上。我们改不了根本（不允许加新内容），
但可以把右边那一列做厚——**这是 P3"允许加法"应该用的地方**。

### ⚠ 一个必须承认的张力

A 档的抗性封顶（`ResFi(H)` 等封顶 100）**提升了公平性（S1），但同时抹平了"区域 × build"的差异**：

- 改前：2 个区域对冰系 100% 无解 → "冰法不能去那里"是个真实约束
- 改后：0 个死角 → 所有 build 都能去所有地方 → **选哪个区域只取决于产出，不取决于你的 build**

差异减少 = 决策减少 = 更接近"哪里产出高就去哪"的单一最优解。

**所以 S1 和 S5 在这里是冲突的，需要别的地方把差异补回来：**

| 补法 | 落点 | 成本 |
|---|---|---|
| 让不同区域产出**不同类别**（而不是都"什么都能掉"） | `levels.txt` 的 alvl / TC 分配 | 中，需要造 TC |
| 让不同区域有**不同门槛**（怪物强度、免疫组合） | `monstats` / `levels` 密度 | 中 |
| 给"难打的地方"**专属产出** | 新增 TC 行（P3 允许） | 中 |

**这是下一步的主要工作**，比继续调掉落权重更有价值。

## 3. 现状为什么"不像游戏"（数据）

### S1 违反：免疫墙

149 个怪物对单元素 build 无解（抗性 > 可破上限 120）；2 个区域 100% 无解。
→ 已做 A1（封顶 100），无解降到 18 个、死角清零。**这条已修。**

### S2 违反：零战斗的高频抽取点

按 `/players 8`、每小时 Good 判定次数（符文走这条路）：

| 路线 | 事件密度 | 单次 Good 概率 | Good/小时 | 需要战斗？ |
|---|---:|---:|---:|---|
| **崔凡克**（9 只/趟、30 秒/趟） | 1080 | 23.68% | **256** | ✅（且被冰免疫卡住） |
| **LK 6 超级箱子**（15 秒/趟） | 1440 | 14.81% | **213** | ❌ 不需要 |
| 牛场 | 3000 | 4.17% | 125 | ✅ |
| 白怪（Act5 近战） | 3000 | 2.78% | 83 | ✅ |
| 暗金怪 | 48 | 6.45% | 3 | ✅ |
| 精英怪 | 96 | 1.50% | 1 | ✅ |

**两个关键因果：**

1. **决定收益的是"事件密度"**。箱子零战斗 → 天然能堆出 6 倍密度。
2. **精英/暗金在数学上不可能成为符文主来源**：它们每小时只有几十次事件，
   而白怪/箱子是几千次。要让 48 次/小时追上 83 次/小时，单次概率得超过 170%——不存在。

所以"让打精英怪变值钱"这条路走不通；**真正该砍的只有零战斗的高频源**。

### S3 违反：死内容

- A3 铁狼：HP −37%、物理伤害 −54%、雇价 **+40%**；A5 野蛮人：伤害 −23%、雇价 **+113%**
- 同职业技能差距 20 倍（亚马逊 Power Strike 62.9 伤害/法力 vs Magic Arrow 3.0）

### S4 违反：稀有度是彩票

崔凡克 Jah 约 1/75000 击杀。这不是"长期目标"，是"没有目标"——
玩家无法规划"我要去刷什么换 Sur"，只能无脑重复。

## 4. 五条杠杆（按收益排序）

### L1 · 收益挂钩挑战：把"抽取次数"换成"处理难度"

**核心动作：给资源分工。**

| 资源 | 来源 | 理由 |
|---|---|---|
| 金币 / 宝石 / 装备 / 珠宝 | 箱子、白怪、Junk | 补给品，低频决策 |
| **符文（构筑核心）** | **精英 / 暗金 / Boss** | 只有"打硬目标"才能拿到力量 |

实现（已落地：`patches/economy.py`）：
- 地狱箱子 `Good` 权重归零（15 张 `Act N (H) Chest A/B/C`），权重自动让给金币/装备/Junk
  → 箱子继续给补给，但**不再产符文**
- 精英 `Citem` 3→6、暗金 `Uitem` 4→8（点缀，不是主来源）
- 白怪 / 牛场 / 崔凡克**一律不动**：它们本来就是战斗源

**实测效果**（`docs/p1-economy.md`）：

| 路线 | Good/小时 前 | 后 |
|---|---:|---:|
| LK 超级箱子 | 213 | **0** |
| 崔凡克 | 256 | 256 |
| 牛场 | 125 | 125 |
| 白怪 | 83 | 83 |
| 暗金 / 精英 | 3 / 1 | 6 / 3 |

→ **符文路径全部落在战斗上**，且总量级持平（最高仍 125~256）。**推进 S2。**

**这不是"惩罚玩法"**：砍掉箱子之后，战斗路径的产出本来就够用（83~256），
玩家不需要补偿——P1 说总量不变，正好对上。

#### L1b · 打怪掉落"像翻箱子"（`patches/drops.py`）

发现：**怪物和箱子的掉落构成几乎一模一样**（gld 35%、Junk 35%、Equip 25%、Good 3~5%），
差的只有 `Picks`——箱子 4、怪物 1。所以"让怪物掉得像翻箱子"= 提 `Picks`，不用动构成。

`MONSTER_PICKS = 2`（白怪 1.67 件/杀、牛场翻倍），理由是它让战斗路线的产出
刚好等于原 LK 的量级（167/250 vs 186/213），**P1 保住**。取 4 会让牛场冲到 500/h
（原 LK 的 2.35 倍），违反 N9。

#### ⚠ 一个被验证抓到的错误（记录在此，防止再犯）

L1 第一版把 `Act N (H) Chest A/B/C` 的 `Good` 清零了，但**LK 那 6 个超箱走的是
`Act N (H) Super A/B/C`**（`Picks=-4`，引用 `Uitem`+`Cpot`），完全没被改到。
更糟的是：同一次改动把 `Uitem` 的 `Good` 从 4 提到 8，而超箱正是通过 `Uitem` 拿符文
→ **实际效果是给超箱加了 87% 的符文**，方向反了。

修法：把超箱的 `Uitem` 引用换成 `Equip`（超箱继续给装备+药水，断掉符文路径）。
用 `tools/p1_economy.py` 一跑就能看出来——**这就是有量化工具的价值**。

### L2 · 稀有度从"彩票"改成"里程碑"

- 提高符文链的产出（`Act N (H) Good` 里 `Runes` 的权重、或 `Runes` 链内部高档权重）
- 目标可规划：玩家能算"刷 X 小时大概能出 Y"
- **注意**：这条必须和 L1 一起做。单做 L2（提高掉率）会让箱子更强，反而更糟。

**推进 S4。**

### L3 · 消除无解，保留区域特色

- 已完成（A1：抗性封顶 100）
- 下一步是检查"是否还挡必经主线"（B3）
- 原则：区域可以"难"，不可以"不可能"

**推进 S1。**

### L4 · 给死内容一个理由（而不是加数值）

- **佣兵**：A3 加生存（不动技能）、A5 只改定价（不给光环，否则是第二个 A2）
- **废技能**：这是最难的一条。协同改不了，所以**只能靠物品/配方**：
  - 让某些暗金/套装给废技能加成（`uniqueitems` 的 skill 字段）
  - 或用 cube 配方提供一个"技能转换"的构筑路径
- **不做**：直接改技能本体伤害到"能打"——那只会造出第二个火球，职业特性反而消失

**推进 S3。**

### L5 · 削减与玩法无关的摩擦

- PlugY：共享仓库、无限页、快捷施法、天梯符文之语
- 零 txt 风险，纯收益

**推进 S3（间接）。**

## 5. 新的负面清单（v2）

| # | 不做 | 理由 |
|---|---|---|
| N1 | 技能协同 | 硬编码，txt 无法表达 |
| N2 | 新增技能/物品/地图/怪物 | 越过"骨架"线，成本与风险失控 |
| N3 | 改 UI / AI | 需要 Dll，且与我们能做到的收益不成比例 |
| N4 | 直接改废技能本体伤害到"可用" | 会抹平职业差异，变成第二个火球 |
| N5 | 动 `itemstatcost.txt` 的 Save Bits / stat ID | 毁存档 |
| N6 | 动 `inventory.txt` | 与 PlugY 格子数失配 |
| N7 | 重做近战/法系整体曲线 | 需要改 `weapons.txt` 全表 + 攻击帧，且无法离线验证 |
| N8 | 修"玩家自己选择的效率玩法"（如自删 `.map` 重随地图） | 那是玩家行为，不是游戏缺陷 |
| N9 | 缩短"毕业后再刷"的时长 | 那是 D2 的设计支柱，砍掉就不是 D2 了（见 §2.5） |
| N10 | 把所有区域都改成"什么都能掉" | 会抹平路径差异，让 S5 失效 |

## 6. 已定参数（决策记录）

| 参数 | 决定 | 影响 |
|---|---|---|
| **P1 毕业时间** | **不变** | 不提高符文总产出，L1 只做"再分配"；L2 的"提高掉率"**取消** |
| **P2 提高地狱难度** | **不提** | 不动 `monlvl`/`difficultylevels` |
| **P3 允许加法** | **允许** | 可以新增 cube 配方 / TC 行 —— 这是唯一能绕过"协同硬编码"的杠杆 |

> P1 不变 ⇒ S4（失败可归因）只能靠 L1 解决一半：**你打不到符文是因为你没去能打的地方，
> 而不是因为运气**。剩下的一半（1/75000 的绝对稀有度）不解决——这是"保持原版手感"的代价。
>
> P3 允许 ⇒ L4 的"废技能"仍不能改技能本体，但可以用**装备给予的技能（oskill）**或
> **cube 配方**给它一条路。这是后面要做的主要加法方向。

### 原待定项（保留说明）

### P1 · 目标毕业时间

原版：HR 理论上无限时间。改动后要一个明确的目标。

- 保守：`200 小时`"感觉毕业"（约等于原版的 1/5）
- 激进：`100 小时`（刷完一套毕业装 + 几个 HR）

→ 决定 L2 的掉率倍数。

### P2 · 是否允许提高地狱难度来换掉率

"提高掉率"必然缩短寿命，唯一的对冲是"让单次挑战更贵"。

- 允许：`monlvl` 的 HP/伤害曲线小幅上调（例如 Hell 怪物 HP +20%）
- 不允许：只提掉率，不动难度 → 游戏会变得更容易且更短

→ 决定 L2 能否成立。

### P3 · 是否允许"加法"（新增 cube 配方 / 新增 TC 行）

这是唯一能绕过"协同改不了"的杠杆，也是让废技能有救的唯一途径。

- 允许：新增 cube 配方（低成本、高杠杆，且不引入新物品）
- 不允许：L4 的"废技能"就只能放弃

## 7. 验证方法（沿用已有工具链）

每次改动后固定跑：

```bash
python3 -m tools.build                        # 构建 + changelog
python3 -m tools.p1_immunity --overlay mod    # S1：无解怪物/死角区域数
python3 -m tools.p1_merc                      # S3：佣兵差距
python3 -m tools.validate                     # 结构校验
```

S2（收益挂钩挑战）需要新工具：**`tools/p1_economy.py`** —— 按路线算"每小时 Good / 符文判定次数"，
把上面 §3 那张表变成可对比的前后报告。这是 L1 能不能验收的关键。

S4（失败可归因）目前只能靠"目标时间内能否达成"实测，无法离线验证。

## 8. 一句话

> **v1 是"修 D2 的错"，v2 是"修 D2 的激励结构"。**
> 不动玩法骨架，只改"为什么值得玩"——让玩家的选择、技巧、构筑决定结果，
> 而不是让"点箱子的次数"和"随机数"决定结果。
