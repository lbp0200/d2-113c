# 进游戏后的验证清单

> 这份清单只回答一件事：**每一处改动到底有没有按预期生效，没生效要改哪里。**
> 装机与部署步骤在 [runbook.md](runbook.md)（§1~§4），这里从"已经能进游戏"开始。
>
> 全部改动都是纯 txt，**没有一行 Dll**，所以每一项都能单独回滚：改回对应常量、重跑
> `python3 -m tools.all` 即可。

## 怎么用

每一项都写四件事：

1. **验什么** —— 这条改动是什么
2. **怎么验** —— 具体动作（去哪、看什么）
3. **判据** —— 什么结果算通过
4. **不通过怎么办** —— 改哪个文件的哪个常量

**如果时间只够验三件，就验 A1、B1、B2** —— 这三条错了，后面的结论全部作废。

## 阶段 A · 部署是否真的生效（先过这关）

### A1 · txt 真的被读了

- **怎么验**：进游戏后看 `data\global\excel\*.bin` 的修改时间；再看任意一只地狱怪的抗性行为
  （例如 Act 1 的 `zombie1` 冰抗：原版 120，改动后应表现为"能被降抗打到"）
- **判据**：`.bin` 时间戳 = 你同步后的时间；且**不是**未改动的原版行为
- **不通过**：`Game.exe -direct -txt` 参数没生效 / 文件没同步到位（用 `robocopy /E`，**不要 `/MIR`**）

### A2 · 抗性封顶生效

- **怎么验**：找一只原版绝对免疫的怪（`boneprison`、`bonewall` 毒抗 200 那一类）
- **判据**：它们**仍然是免疫**（封顶只把 110~250 压到 100，`>=1000` 的设计性绝对免疫没动）
- **不通过**：`patches/balance.py` 的排除条件写错了

### A3 · 新加的 4 行 cube 配方被读到了

- **怎么验**：`魔法头盔 + 珠宝 + 埃欧(r16) + 完美红宝石` 放盒子里合成
- **判据**：出一个**橙色 craft 头盔**，tooltip 里有一行「**−X% 敌人火焰抗性**」
- **不通过**：`cubemain.txt` 追加行没被引擎读取 → 这条路要换方案（改成改现有暗金）
  - 注意：这是本轮唯一**没被社区大量验证过**的机制，失败概率不低

## 阶段 B · 机制硬伤（会推翻设计判断，优先级最高）

### B1 · `Super` 到底是超级暗金怪，还是超箱

- **为什么重要**：`patches/economy.py` 把 `Act N (H) Uitem A/B/C` 的 Good 权重 4→20。
  若 `Super` 是"超箱"，这条会把 LK 超箱的符文产出翻 5 倍，整个 L1 设计反过来。
- **怎么验**：找一只**超级暗金**（Act 1 `Corpsefire`、Act 3 `Stormtree` 之类），杀它看掉落
- **判据**：**掉金币** + 掉 2~4 件 → 是怪物（当前判断正确）；**不掉金币、只掉装备药水** → 需要重新判断
- **不通过**：改 `patches/economy.py` 里 `Uitem` 那条的权重，或给超箱单独加 TC 行

### B2 · 穿透到底能不能破免疫

- **为什么重要**：`docs/p2-areas.md` 的全部结论都建立在「**不能**」这条规则上
  （所以电系那 6 个归零区域一个没少）。若实际能破，电系的结论要重写。
- **怎么验**：法师点满 `Cold Mastery`（−115%），去打一只**冰免**怪（Act 5 的 `frozenhorror` 一类）
- **判据**：**完全打不动** → 不能破（当前规则正确）；能打出伤害 → 能破，`tools/p2_areas.py`
  的 `factor()` 要改成 `breaking` 口径，并重跑 §6/§7 的数字
- **不通过**：改 `tools/p2_areas.py` 的默认规则 + 重写 `p2-balance-plan.md` §6/§7

### B3 · 火掌握的新穿透会不会被九头蛇吃两遍

- **为什么重要**：`Hydra` 的 `passivestat2` 本来就在读 `passive_fire_pierce`；
  现在 `Fire Mastery` 开始**发放**它，可能叠加成双倍
- **怎么验**：法师点满火掌握，对同一只高火抗怪分别用 `Fire Ball` 和 `Hydra`，比伤害比例
- **判据**：九头蛇的伤害 ≈ 火球按面板比例推算的值（不是明显翻倍）
- **不通过**：`patches/p2_skills.py` 里把 `Fire Mastery` 的 `passivestat2` 换到别的 stat
  或改用别的发放方式

### B4 · 技能描述里看不到穿透（已知代价，确认影响可接受）

- **怎么验**：看火掌握 / 电掌握的技能说明
- **判据**：说明里**没有**降抗那一行，但实际伤害确实变高（打高抗怪明显）
- **不通过**：不是 bug，是刻意取舍（改描述要动 Big5 字符串表）。若觉得不可接受，
  只能换方案：把穿透做成装备（装备 tooltip 会自动显示）

### B5 · 精英/暗金怪的 Good 提升有没有过头

- **怎么验**：刷 20 只以上精英/暗金，记"每次掉几件、几件是符文路径"
- **判据**：`docs/p2-audit.md` 的预期是精英 14.6% / 暗金 25.6% 的 Good 概率；
  体感不应出现"每只精英都喷一堆符文"
- **不通过**：`patches/economy.py` 的 `Citem 3→40` / `Uitem 4→20` 调小

## 阶段 C · 数值与手感

### C1 · `Picks = 4` 的地面密度

- **怎么验**：清一场 Act 5 白怪，看地面物品量、是否有明显卡顿
- **判据**：每次击杀约 1.7~3.3 件，能看清地面；不需要"等地面消失"
- **不通过**：`patches/drops.py` 的 `MONSTER_PICKS = 4` → 3（这是唯一的力度旋钮）

### C2 · `Picks = 4` 有没有撞引擎上限

- **怎么验**：注意是否出现"怪死了但少掉东西"、或同一群怪只有前几只掉
- **判据**：没有系统性缺件
- **不通过**：同上，把 `MONSTER_PICKS` 降到 3 或 2

### C3 · 刺客 `Inferno Sentry`

- **怎么验**：24 级刺客放一个喷火哨卫，和雷光守卫对比清怪速度
- **判据**：不再是"明显没用"的级别（改动把 L20 从 44-50 提到 139-160）
- **不通过**：`patches/p2_skills.py` 里 `Inferno Sentry` 的 ×3.2 调大或调小

### C4 · 死灵 `Poison Nova`

- **怎么验**：30 级毒死灵对一群白怪放一次，看 2 秒内掉血总量
- **判据**：约 800 总量（改动前 625），且法力 16 能连放
- **不通过**：`patches/p2_skills.py` 里 `Poison Nova` 的速率倍数 / `mana`

### C5 · 德鲁伊 `Armageddon` 的法力手感

- **怎么验**：30 级火德连放陨石，看蓝够不够连
- **判据**：25 点法力能维持输出（改动前是 35，烧不动）
- **不通过**：`patches/p2_skills.py` 里 `Armageddon` 的 `mana`

### C6 · 法师三系的实际强弱（T2 判定）

- **怎么验**：同一套装备，分别用火（改后）/ 电（改后）/ 冰，各刷同一片区域
- **判据**：三系各有明显更好的场景（火单体、电清场、冰高抗）；
  **不应**出现"冰系在其他两系面前毫无存在感"或反过来
- **不通过**：调 `patches/p2_skills.py` 里对应系掌握的 `Param3/Param4`（穿透）或 `Param1/Param2`（伤害）

### C6b · 雇佣兵（A3 铁狼 / A5 野蛮人）

- **验什么**：`Hireling.txt` 里 A3 地狱档 HP ×1.35（85 级 1025 → 1381）、
  A3 雇价 → 12000、A5 雇价 32000 → 15000
- **怎么验**：地狱带 A3 铁狼 30 分钟；再买一次 A5 野蛮人看价格
- **判据**：A3 仍然比 A2 容易死（只是「不那么容易」）；A5 调价后**仍然没人选**
- **不通过**（A3 变成肉盾）：`patches/merc.py` 里把 `1.35` 降到 1.2
- **不通过**（A5 突然变成最优解）：说明价格改过头，`15000` 往上调
- 注意：**没有给 A3/A5 加光环** —— A2 强的根源是「只有它有光环」，这是刻意保留的职业差异

### C8b · 重做的两个符文之语（毒液 / 天底）

- **验什么**：`Venom` 的两个凑数充能 → `pierce-pois 15~20` + `pois-len -50 帧`；
  `Nadir` 的两条负面（`light -3` / `gold -33`）→ `+20 法力` / `+25% 回蓝`
- **怎么验**：毒死灵做一把 3 孔 `Venom`，配降抗诅咒打地狱；再做一个 `Nadir` 给低级法系
- **判据**：毒**跳得更快**（同一目标掉血更集中）、但**总伤害没有明显超过死亡之网**；
  天底不再有负面属性
- **不通过**（毒太强）：`patches/p3_runewords.py` 里 `pois-len` 从 −50 改回 −30，或去掉 `pierce-pois`
- **不通过**（毒没感觉）：先确认 `pois-len` 的语义（是帧数还是百分比）—— 这条写进待验证

### C8 · 中间层降抗（`Radiance` 带信念 L3）

- **验什么**：`Runes.txt` 里 `Radiance` 的 `light +5` 换成了 `aura / Conviction / 3`
- **怎么验**：用 Nef+Sol+Ith 做一顶 3 孔头盔（req 27），给佣兵戴；
  再让一个**没有降抗**的职业（德鲁伊/刺客/亚马逊）打地狱里火抗 75~95% 的怪
- **判据**：明显比裸装快；但**打火免怪仍然打不动**（信念对免疫怪只有 1/5）
- **不通过**（噩梦全无压力 = 太强）：`patches/p3_runewords.py` 里 `T1Min1/T1Max1` 改成 2
- **不通过**（还是没感觉 = 太弱）：改用备选 —— `Enlightenment`（req 45 躯干）+ 信念 L5
- 设计说明见 [p3-runes-plan.md](p3-runes-plan.md)

### C7b · 物理弓的伤害手感（实测反馈驱动的一条）

- **验什么**：`Multiple Shot` / `Strafe` 的 `SrcDam` 96→128、`LevToHit` 空→10
- **怎么验**：新建弓马，1 级起用普通攻击 → 6 级后一直用 `Multiple Shot`，打到 Act 2
- **判据**：清一群小怪不再是「打半天」；和同进度的近战职业比不落下风
- **不通过**（如果**太强**了，一屏秒）：`patches/p2_skills.py` 里 `_BOW_SRC` 从 128 降到 **112**
- **不通过**（如果**还是弱**）：再考虑动 `Weapons.txt` 的弓基础伤害（×1.3），
  但那会影响罗格佣兵与所有弓类底材、暗金/套装弓，要单独评估

### C7 · 亚马逊 `Fire Arrow` / `Cold Arrow` 的低级手感

- **怎么验**：新建弓马，1 级开始用火焰箭、6 级用冰箭
- **判据**：法力 8 / 12 时能连续放，不再是"两下就没蓝"
- **不通过**：`patches/p2_skills.py` 里对应 `mana`

## 阶段 D · 装备层（只验 6 个目标，其余不动）

### D1 · 4 件"无强属性"暗金到底有没有人用

- **验什么**：`War Bonnet`、`Lenyms Cord`、`Coif of Glory`、`The Centurion`（全 req ≤ 14）
- **怎么验**：玩一个 1~20 级的新角色，看是否真的会捡起来穿
- **判据**：如果**确实一次都不会穿** → 它们可以被赋予一个新身份；如果会穿 → 保持原样
- **不通过**（即判定该改）：新增一个补丁文件（`p3_*.py`，尚未创建），一次只给一件加一个明确身份

### D1b · 重做的 7 件弱暗金/套装单件

- **验什么**（`patches/p3_uniques.py`）：
  `Steelpillar` 加 `ease -25%`（力需 165→124）、`Razortine` 伤害 60-80% + `ease -20%`、
  `Venomsward` 补 hp/regen、`Heavenly Garb` 对不死→**对恶魔**、`Gravepalm` 补 `crush 10`、
  `Hawkmail` 冰抗 30/跑速 25、`Magnus' Skin` 补 20% FHR + 30 生命
- **怎么验**：正常掉落这几件时看 tooltip；重点验 `Steelpillar` 能不能 124 力举起来
- **判据**：每件都能说出"我为了哪一项穿它"；且**没有一件强到挤掉同槽位的现有最优**
- **不通过**（太强）：把新增那条属性的数值减半
- **不通过**（还是没人穿）：说明问题不在数值 —— 记录下来，不再硬加

### D2 · `Infernal Tools` 套装

- **怎么验**：5 级角色凑这套（腰带 / 头盔 / 法杖）的难度与收益
- **判据**：2 件加成（毒伤 25）是否值两个部位
- **不通过**：改 `sets.txt` 的 `PCode2a/2b`（这是 32 套里唯一"必须凑齐 3 件"的）

### D3 · `Spirit` 的性价比

- **怎么验**：需求 25 做出 `Spirit`（4 孔剑/盾），和同等级的暗金、套装比
- **判据**：它是"明显默认选择"但不至于让整档装备消失
- **不通过**：`runes.txt` 里调它的加成（注意：这是动 RW，影响面大，要单独评估）

## 阶段 E · 收尾

### E1 · 主线能通关

- **怎么验**：一个角色从 Act 1 到 Act 5 通关一次
- **判据**：没有哪一段因为抗性/伤害改动变成"过不去的墙"
- **不通过**：`patches/balance.py`（抗性封顶范围）

### E2 · 存档兼容

- **怎么验**：用改动后的存档，换回 `vanilla/` 数据启动一次
- **判据**：存档能读、装备不消失
- **不通过**：说明改动动了存档相关的表（本轮理论上不涉及 `itemstatcost` 的 Save Bits）

### E3 · 回滚演练

- **怎么验**：`rm -rf data/`，把备份的原版 `data/` 放回，启动
- **判据**：完全恢复原版行为
- **不通过**：说明有文件被改在 `data/` 之外

## 一页速查：失败 → 改哪里

| 症状 | 改这里 |
|---|---|
| txt 没生效 | 启动参数 `-direct -txt` / 同步方式 |
| 掉落太多/太少 | `patches/drops.py` 的 `MONSTER_PICKS` |
| 精英/暗金太肥 | `patches/economy.py` 的 `Citem` / `Uitem` 权重 |
| 某系太强/太弱 | `patches/p2_skills.py` 里该系掌握的 `Param1~4` |
| 技能法力不对劲 | `patches/p2_skills.py` 里该技能的 `mana` |
| craft 合不出来 | `patches/p2_items.py`（先确认 B2 的 `cubemain` 是否被读） |
| 免疫打不动/太好打 | `patches/balance.py` 的抗性封顶 |

改完任何一处，都要重跑：

```bash
python3 -m tools.all --reports      # 重建 mod/ 与全部报告
python3 -m unittest discover -s tests -t .   # 114 项单测
```
