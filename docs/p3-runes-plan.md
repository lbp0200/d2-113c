# P3 · 降抗三层设计（补「信念之下」的中间层）

> 目的只有一个：**让没有降抗的职业的元素线不再冷门**。
> 数据全部来自 [`p2-areas.md`](p2-areas.md)（`tools/p2_areas.py`），可重跑。

## 问题的数字

全游戏只有三个技能能降敌人抗性：**冰掌握 −115 / 信念 −125 / 降抗诅咒 −70**。
德鲁伊、刺客、亚马逊**一个都没有**。

按 126 个钉了怪的区域取平均的「环境系数」（0 = 完全打不动，1 = 无抗性）：

| 配置 | 系数 | 相对冰法 |
|---|---:|---:|
| 无降抗职业（裸装） | 0.61 | 45% |
| + 元素穿透 craft（−20 / +15%） | 0.88 | 64% |
| **+ 光辉（信念 L3，−40）** | 0.92 | 67% |
| **+ 光辉 + craft（−60 / +15%）** | **1.23** | **89%** |
| 冰法（自带 −115，零装备） | 1.37 | 100% |

**关键结论：单个来源都不够，必须「佣兵光环 + 自己头盔」两件组合才到 89%。**
这是刻意的 —— 让"凑装备"成为构筑的一部分，而不是一件件通吃。

## 三层结构

| 层 | 来源 | 效果 | 获取方式 | 定位 |
|---|---|---|---|---|
| 0 | 无 | — | — | 冷门 |
| 1 | 元素穿透 craft（4 配方） | 该系 −10~20 / +10~15% | 魔法头盔 + 珠宝 + 埃欧 + 完美宝石 | 噩梦 |
| **2（本次）** | **`Radiance`（光辉）3 孔头盔** | **信念 L3 = 全元素 −40** | Nef + Sol + Ith（req 27） | **噩梦后期 ~ 地狱前期** |
| 3 | 无限（信念 L12） | −85 | Ber + Mal + Ber + Ist | 终局 |

## 为什么改 `Radiance`

它现在是一条"光影"：6 条属性里第一条是 **`light` +5（光环半径）** —— 纯废物。

| 字段 | 前 | 后 |
|---|---|---|
| `T1Code1` | `light` | **`aura`** |
| `T1Param1` | （空） | **`Conviction`** |
| `T1Min1` / `T1Max1` | 5 / 5 | **3 / 3** |

- **拿掉的是废物属性，不是有效属性** → 总强度基本不变
- 写法照抄 `Infinity` 的 `aura` + `param=Conviction` + min/max=等级
- 只改 `Runes.txt` 一行，**不需要动 Big5 字符串表**（名字沿用）
- 头盔位置对佣兵最友好，不占玩家的核心槽

## 三个必须记住的限制

1. **信念对免疫怪只按 1/5 生效**：−40 对免疫怪只有 **−8**。
   它解决的是「高抗怪打不快」，**不是**「打不动」。
2. **玩家自己也能戴**：任何职业戴上都有信念 L3。这会部分稀释圣骑士的信念 ——
   但无限早就稀释过了，而且骑士自己点满能到 −125。
3. **信念只管火 / 冰 / 电**，毒系吃不到（毒系已经靠降抗诅咒）。

## 回滚与调整

- 回滚：把 4 个字段改回 `light` / 空 / 5 / 5，重跑 `python3 -m tools.all`
- 太强（噩梦全无压力）：`T1Min1/T1Max1` 改成 **2**（−35）
- 太弱（还是没感觉）：参考备选的 `Enlightenment`（req 45 躯干）+ 信念 L5（−50），
  单独 0.99（72%）、配 craft 1.31（96%）；代价是躯干位会和 `Fortitude` / `Enigma` 竞争

# 第二轮：重做两个「垃圾符文之语」

> 判据仍是 **E1（每件一个身份）** 与 **E2（不许造新 BiS）**。
> 候选来自用户/社区名单，逐件用数据核对过（`docs/p3-junk-list.md` 的方法）。

## ① 毒液 `Venom`（Tal + Dol + Mal，req 49，任意武器）

**现状**：只有 2 条强属性 —— 一点毒伤 + 7% 吸蓝 + **两个凑数的充能技能**。

**难点**：毒系确实缺一把终局武器（死亡之网是极稀有暗金），
但直接加「毒穿透 + 毒系技能伤害」会立刻超过死亡之网：

| 配置 | 环境系数 |
|---|---:|
| 毒死灵 + 降抗诅咒（−70） | 1.20 |
| **+ 死亡之网（−50）＝ 现状最强** | **1.55** |
| 任何「−20 穿透 + 20% 毒伤」组合 | **1.65 ✗ 超了** |

**做法：走「时间」不走「数值」**

| 字段 | 前 | 后 |
|---|---|---|
| `T1Code3` | `charged`（凑数） | **`pierce-pois` 15~20**（低于死亡之网的 40~50） |
| `T1Code4` | `charged`（凑数） | **`pois-len` −50 帧（−2 秒）** |
| 其余 | `dmg-pois` / `ignore-ac` / `manasteal` | **不动** |

`pois-len` 是**帧数**（原版 `Hellplague` +150 帧、`Rakescar` +75 帧，
而 Venom 自己的 `dmg-pois` 持续 175 帧）→ 减到 125 帧。
**毒的总量不变，但更快跳完 = 实战 DPS 更高。**

**验收**：毒死灵（降抗诅咒 + 这把武器）环境系数 **1.375 < 1.55**（死亡之网）✅
**身份**：让毒从「慢热」变「能打」，而不是「比死亡之网更强」。

**身份**：法系开荒头盔（回蓝）。
