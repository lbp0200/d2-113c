# P2 · 逐职业技能系平衡计划

> 目标不是"每个技能都变强"，而是**让每个技能系都有存在的理由**。
> 一个系只要找不到"选它最优"的场景，它就是死内容 —— 不管它的数字看起来多漂亮。

---

## 1 · 判据

| 编号 | 判据 | 怎么验 |
|---|---|---|
| **T1 每系一个胜场** | 每个系至少有一个「选它最优」的场景 | 场景矩阵里该行至少 1 个 ✅ |
| **T2 没有全能系** | 没有一系在 4 个以上场景最优 | 场景矩阵里该行 ✅ ≤3 |
| **T3 等价交换** | 只加不改，或"拿走 A 换给 B"，不凭空加总量 | 看 `docs/changelog.md` 的数值变动 |
| **T4 数值可预演** | 改之前先算出各抗性段的倍率，改之后用同一公式复核 | `tools/p1_skills.py` |

原始伤害数字**不作为判据**。Frozen Orb 的伤害/法力只有 8.8（法师 22 个技能排第 14），
却是最常被使用的技能 —— 说明形态和抗性穿透的权重远高于数字。

## 2 · 场景矩阵（"胜场"的定义）

| | 场景 | 什么算赢 |
|---|---|---|
| **M1** | 开荒（零装备、自给自足） | 能独自过地狱，不靠特定装备 |
| **M2** | 密集清场（白怪群、效率） | 单位时间击杀数最高 |
| **M3** | 单体攻坚（暗金 / BOSS） | 对单目标 DPS 最高 |
| **M4** | 高抗 / 免疫区 | 抗性 75%+ 与免疫怪面前还有输出 |
| **M5** | 安全 / 容错（HC、手残） | 有肉盾、控制、远程、回血 |
| **M6** | 终局极限（满装备上限） | 装备堆满后的天花板最高 |

一个系赢 ≥1 个（T1）、≤3 个（T2）。

## 4 · 三层解法（按"能碰什么"分层）

### 第 1 层 · 技能层（`skills.txt`，最安全）

- 改本体伤害曲线 / 法力 / 需求等级
- 改 `Param` + `passivestat`（这就是 A2 用的手段）
- **限制**：协同改不了（Dll 硬编码）；新技能拿不到技能点（技能树硬编码）

### 第 2 层 · 装备层（`cubemain.txt`，帮所有职业）

`itemstatcost.txt` 里 4 个 `passive_*_pierce` 就是「−X% 敌人抗性」的实现，
**装备上会自动显示成 tooltip**（`descfunc=20` + 每系独立的 `descstrpos`），
比技能描述还清楚——这正好绕开"技能描述改不了"的问题。

原版自己给出的穿透来源（全部列在 `UniqueItems.txt` / `SetItems.txt`）：

| 装备 | 元素 | 穿透 |
|---|---|---:|
| 死亡之网 | 毒 | 40~50 |
| 女族长 | 冰 | 20~35 |
| 塔格奥之翼 | 毒 | 25 |
| **乌鸦之灵**（德鲁伊头盔） | **火** | **10~20** |
| 塔拉夏的眼球 | 火 / 电 | 15 |
| 格利风之眼 | 电 | 15~20 |
| 曼颂的教训 / 雷霆之击 | 各系 | 7~15 |
| 彩虹刻面（可镶嵌多颗） | 各系 | 3~5 / 颗 |

**这条路已经做成了**：`patches/p2_items.py` 新增 4 个 craft 配方（见 §6）。
选 craft 而不选新符文之语/新暗金，是因为后两者都要往字符串表里加名字，
而整合版是 **Big5 繁体**，改 tbl 的风险远高于收益。

### 第 3 层 · 明确不碰

- **协同加成**（Dll）→ 火系"投入 80 点才成立"的结构无法改
- **锤子弹道、Whirlwind 判定、Nova 环形** → 硬编码
- **技能树前置关系** → 硬编码

## 5 · 推进顺序

按"该系是否**完全没有**胜场"排，先修死内容，再调强弱。

| # | 系 | 状态 | 手段 | 备注 |
|---|---|---|---|---|
| 1 | 法师 · 火 | ✅ **已完成（A2）** | 技能层：伤害 163%→100% + 穿透 −45% | 75% 抗性处与冰系相等 |
| 2 | 德鲁伊 · 火 | 🟡 **一半** | ✅ 装备层（穿透 craft）；⬜ 还缺技能层的本体伤害 | 他没有掌握技能，技能层只能改伤害数字 |
| 3 | 死灵 · 毒 | ⬜ 待做 | 技能层：把 `passive_pois_mastery`/`_pierce` 挂到 Poison Dagger 或 Lower Resist | 毒还多一层"速率 vs 总量"的坑 |
| 4 | 刺客 · 火陷阱 | 🟡 **装备已就位** | 装备层已完成（共用穿透 craft） | 还需要验"够不够" |
| 5 | 亚马逊 · 元素弓 | 🟡 **装备已就位** | 装备层已完成 | Immolation Arrow 54.8 其实不低 |
| 6 | 法师 · 电 | ⬜ 待决定 | 技能层：`passive_ltng_pierce` 挂 Lightning Mastery | 伤害已最高，给多少要小心 |
| 7 | 法师 · 冰 / 圣骑士 · 战斗 | ⬜ 只观察 | **不砍**（违反 T3），靠抬高别人 | T2 违规是"别人太弱"造成的 |
| 8 | 野蛮人 · 战斗 | ⚪ 承认修不了 | — | 缺 AoE 是硬编码问题 |

### 每一轮的固定流程

1. **诊断**：从 `p1-skills.md` 拿该系的伤害曲线 + 掌握/降抗结构
2. **预演**：手算各抗性段倍率（0/50/75/90/99%），和"标杆系"对比
3. **落补丁**：`patches/p2_skills.py` 里加一段，**一次只动一个系**
4. **验收**：`python3 -m tools.build` + `tools.p1_skills.py --overlay mod --stdout` 复核公式
5. **记账**：更新本文件的进度表 + `TODO.md`

### ✅ 元素穿透 craft（`patches/p2_items.py`）

给"连一个掌握类被动都没有"的职业（德鲁伊 / 刺客 / 亚马逊）一条降抗途径。

| | 内容 |
|---|---|
| 配方 | 魔法头盔 + 珠宝 + 埃欧(r16) + **完美宝石** → craft 头盔 |
| 宝石 | 红=火 / 黄=电 / 蓝=冰 / 绿=毒 |
| mod 1 | `pierce-X` **10~20**（与乌鸦之灵同级，不超过格利风之眼） |
| mod 2 | `extra-X` **10~15%**（+% 该系技能伤害，格利风之眼同款 property） |
| mod 3 | `res-X` **20~30**（craft 该有的护身 mod） |

**为什么是 craft 而不是新符文之语/新暗金**：后两者都要往字符串表加名字，
整合版是 Big5 繁体；而 craft 的输出名就是底材名（"头盔"），
mod 行由引擎按 `itemstatcost` 的 `descstrpos` 自动生成 → **不需要碰 tbl**。

**为什么只有头盔**：头盔只能戴一个 → 最多一条穿透，天然不会叠。

查看原版所有穿透来源（`uniqueitems`/`setitems`）后定的 10~20：
死亡之网 40~50、女族长 20~35、乌鸦之灵 10~20、格利风之眼 15~20、彩虹刻面 3~5/颗。
「合一件 craft」的合理位置就在 10~20 这一段。

**能力提升**（126 个钉了怪的区域取平均「伤害系数」，0=打不动，1=无抗性）：

| 无掌握职业的火系 | 平均系数 |
|---|---:|
| 裸装 | 0.61 |
| +10 穿透 +10% 伤害 | ~0.77 |
| +20 穿透 +15% 伤害 | ~0.88 |

**这不足以让火德追上风德**（还差一个技能本体伤害的档次，25.7 vs 43.8）。
那个缺口要单独在技能层修 —— 也就是下一项待办。
