# 笔记：地狱会不会掉普通底材？（以水晶剑为例）

> 数据源：`TreasureClassEx.txt` / `Weapons.txt` / `ItemTypes.txt`（vanilla 1.13c）。
> 工具：`tools/d2tc.py`（TC 展开，已按表头严格配对，见文末「踩坑」）。

## 结论

**会掉，而且是地狱白装的绝对大头。** 地狱装备掉落里，**低阶底材（武器/护甲等级 ≤30）占 49%~59%**，
精英档只占 11%~26%。这正是"都打到地狱了还满地垃圾"的数据解释。

但"能掉"和"能用"是两件事 —— 见 §4。

## 1. 机制：`weapN` / `armoN` 是按物品等级分带，不是按物品名

`TreasureClassEx.txt` 里查不到 `weap3`、`weap54` 这些行。它们是游戏**按物品的 `level` 自动生成**的带：

```
weapN  =   Weapons.txt 里 level 落在 (N-3, N] 区间的武器
armoN  =   Armor.txt   同理
```

所以 N 是**带上限**，带宽 3。举例：

| 带 | 包含（`level`） |
|---|---|
| `weap3` | Club(1)、Javelin(1)、Short Bow(1)、Short Staff(1)… |
| `weap12` | Pilum(10)、Two-Handed Sword(10)、**Crystal Sword(11)**、Falchion(11)、Voulge(11)、Broad Axe(12)… 共 11 项 |
| `weap54` | Gothic Bow(52)、Truncheon(52)、Martel de Fer(53)、Chu-Ko-Nu(54)、Executioner Sword(54)… |
| `weap87` | Archon Staff(85)、Berserker Axe(85)、Colossus Blade(85)、Giant Thresher(85)… |

> ⚠ `weapons.txt` 里普通/扩展/精英三档是**各自独立的行**，各有自己的 `level`。
> 所以同一个带里可能混着不同档位的物品 —— 带号不等于档位。

## 2. 地狱的装备 TC 是"长链降级"，所以长尾拖到最底层

`Act 1 (H) Equip A` 直接引用的是 `weap54/57/60/63`，但它的条目里有一条**权重极大的降级链**：

```
Act 1 (H) Equip A → Act 5 (N) Equip C → Act 5 (N) Equip B → … →
Act 1 (N) Equip A → Act 5 Equip C → … → Act 1 Equip C → weap3
```

24 跳。所以低阶底材虽然"离得很远"，但因为每一跳的降级权重都远大于高档权重，
**最终分布反而是低阶占多数**。

实测（每个物品槽的期望分布）：

| 根 TC | 低阶 ≤30 | 中阶 33~51 | 高阶 ≥54 | 其中 `weap12` |
|---|---:|---:|---:|---:|
| `Act 1 Equip C`（普通 Act1 后期） | 100% | 0% | 0% | 5.56% |
| `Act 1 (N) Equip A`（噩梦 Act1） | 80.6% | 19.4% | 0% | 6.62% |
| `Act 1 (H) Equip A`（地狱 Act1） | **59.4%** | 29.9% | 10.6% | 4.86% |
| `Act 5 (H) Equip A`（地狱 Act5） | **49.4%** | 24.9% | 25.7% | 4.04% |

## 3. 水晶剑的具体概率

`weap12` 带里有 11 个物品，假设带内均匀：

```
P(水晶剑) ≈ 4.86% / 11 ≈ 0.44%  （地狱 Act1 每次装备掉落）
```

也就是说：**地狱里每掉 200 多件装备，就有一件水晶剑**。不少。

## 4. 但地狱掉的水晶剑，做不了「精神」

这是真正的关键 —— **ilvl 由怪物等级决定，不由 TC 带决定**。

地狱的怪等级 76~85，所以掉出来的水晶剑 `ilvl ≈ 80`。而剑类的孔数上限是：

| `ItemTypes.txt`（Sword） | 值 |
|---|---|
| `MaxSock1`（ilvl 1~25） | **3 孔** |
| `MaxSock25`（ilvl 26~40） | **4 孔** |
| `MaxSock40`（ilvl 41+） | **6 孔** |

所以：

- 地狱的水晶剑 → 拉苏克打孔给 **6 孔**，精神要 4 孔，**废了**
- 噩梦（ilvl 26~40）的水晶剑 → 拉苏克给 **4 孔** ✓
- 例外：白色带孔装备是**随机孔数掉落**的，所以地狱也可能直接掉一个 4 孔水晶剑（运气）

**实用结论**：要做精神，去**噩梦 Act1~Act3**（怪物等级 26~40）打白水晶剑再拉苏克。
地狱掉的那些只能当材料或卖钱。

## 5. 踩坑：`TreasureClassEx.txt` 最后 4 列不是物品

```
... Item9 | Prob9 | Item10 | Prob10 | SumItems | TotalProb | DropChance | Term
... Act 3 (H) Equip B | 1530 | (空) | (空) | 36 | 1566 | 0.977 | 0
```

朴素写法（"从下标 9 开始每两列一组"）会把 `36`、`0.977` 当成物品名，
于是掉落链里出现 `'36'` 这种幽灵条目。**必须按表头 `ItemN` / `ProbN` 配对**。

已封装进 `tools/d2tc.py`，以后别手写递归。

## 6. 附：能不能改成"地狱最低掉扩展"？

> 提议（用户）：地狱难度掉的底材最低应该是扩展档，不然白到地狱了。

### 6.1 为什么原版数据模型表达不了"按档位"

档位（普通/扩展/精英）和 `level` 是**交叉**的，不是分层：

| 档位 | 武器 | 护甲 |
|---|---|---|
| 普通 | 112 项，L0~34 | 68 项，L1~52 |
| 扩展 | 97 项，L28~55 | 67 项，L33~70 |
| 精英 | 97 项，L52~86 | 67 项，L54~85 |

所以同一个"等级带"里混着不同档位：

- `weap54`（L52~54）里同时有 **扩展**（Gothic Bow L52、Martel de Fer L53、Executioner Sword L54）
  和 **精英**（Truncheon L52、Matriarchal Bow L53、Tomahawk L54）
- `weap33`（L31~33）里同时有 **普通**（Great Sword L33、War Scythe L34）和 **扩展**（War Spear L33）

TC 只能按 `weapN`/`armoN` 引用，**没有"引用所有扩展档"的写法**。
要精确实现"最低扩展"，只能显式枚举物品代码另造一批 TC（技术上可行，属于"加内容"）。

### 6.2 就算做到了，也解决不了真正的痛点

**孔数由 ilvl 决定，不由档位决定。**

- 扩展档的水晶剑 = Dimensional Blade，`gemsockets` 同样是 **6**
- 地狱怪等级 76~85 → ilvl ≈80 → 剑类 `MaxSock40` = 6
- 所以拉苏克照样给 6 孔

→ 从"没用的普通白装"变成"没用的扩展白装"，唯一收益是卖价高一点。

### 6.3 如果目标是"地狱别满地垃圾"：有个更简单的旋钮

现状的根源是一条权重：`Act 1 (H) Equip A` 的高带权重合计 **42**，
而降级条目 `Act 5 (N) Equip C` 权重 **1785** —— **97.7% 的掉落都走了降级链**。

把 `(H) Equip` 系列的降级权重乘以 `k` 的敏感度（实测）：

| k | Act1(H) 低/中/高 | Act5(H) 低/中/高 |
|---|---|---|
| 1.0（现状） | 59.4% / 29.9% / 10.6% | 49.4% / 24.9% / 25.7% |
| 0.5 | 58.1% / 29.3% / 12.6% | 40.4% / 20.3% / 39.3% |
| 0.25 | 55.6% / 28.0% / 16.3% | 27.2% / 13.7% / 59.1% |
| 0.1 | 49.3% / 24.9% / 25.8% | 9.2% / 4.6% / 86.2% |
| 0（全切） | 0% / 0% / 100% | 0% / 0% / 100% |

注意 `k=0` 的结果是 **100% 高阶**，不是"最低扩展"：
直接带 `weap75~84`（L73~84）里全是精英档，扩展档根本不在其中。

### 6.4 代价

1. **精英底材变成自动贩卖机**：54+ 档共 187 项（武 103 + 甲 84），全池 508 项
   → 掉池缩到 37%，"找一件完美精英底材"这个终局玩法会消失。
2. **多样性塌缩**：每个区域只掉固定的 12 个带的物品。
3. **孔数问题依然没解决**（见 6.2）。

### 6.5 结论

- 想减噪：`k = 0.25 ~ 0.5`，**不要到 0**。
- 想精确"最低扩展"：需要另造白名单 TC（`patches/drops.py` + 新 TC 表，可生成）。
- **当前建议：先不动。** 低档底材在普通/噩梦供给充足，没有任何玩家受损；
  而"绝大多数掉落是垃圾"是 ARPG 保证稀有度的常规手段
  （D3/D4 才做"难度下限提档"，那是另一个设计世代的做法）。

## 7. 附：多 PP（`/players N`）是不是掉落更多？

**是，但"更多"只体现在数量上，不体现在品质和档位上。**

### 7.1 机制：摊薄 NoDrop

掉落判定是"在 `NoDrop` 权重和物品权重之间抽签"。多 PP 的做法是**把 NoDrop 权重按人数摊薄**：

```
for i in 1 .. players-1:
    NoDrop = NoDrop * (players - i) / (players - i + 1)      # 整数除法
```

这是连乘、逐项约分，结果约等于 `NoDrop / players`。所以 /players 8 时 NoDrop 只剩 1/8。
（D2 用整数逐步除，所以和"精确除以 8"有一点点差异，下面的数按整数版算。）

### 7.2 效果因 TC 而异 —— 差距很大

| TC 类型 | 例 | NoDrop | Picks | p1 命中物品 | p8 | 倍数 |
|---|---|---:|---:|---:|---:|---:|
| 普通怪物主掉落 | `Act 5 (H) H2H A` | 100 | 1 | 37.5% | 83.3% | **2.22×** |
| 箱子 | `Act 3 (H) Chest B` | 100 | 4 | 29.6% | 77.8% | **2.63×** |
| 崔凡克议会 | `Council (H)` | **19** | 3 | 65.5% | 94.7% | **1.45×** |
| 装备/宝物子链 | `Act 5 (H) Equip A` / `Good` | **0** | — | 100% | 100% | **1.00×** |

两条非直觉的结论：

1. **崔凡克对 `/players` 最不敏感**。因为它的 NoDrop 只有 19（物品权重 36），
   本来就有 65.5% 命中率，摊薄后只多 45%。而怪物 HP 会涨 4.5 倍
   → **`/players 8` 刷崔凡克其实是亏的**（产出 +45%，血量 +350%）。
2. **箱子最敏感**（2.63×）。这正是"下库拉斯特超级箱子必须 `/players 7~8`"的原因——
   LK 的符文产出几乎全部来自箱子，而箱子的 Picks=4、NoDrop=100，摊薄收益最大。

### 7.3 `/players` 不影响什么

- **不改变品质**：unique / set / rare / magic 的概率由 `itemratio.txt` 决定，与人数无关
- **不改变档位分布**：装备子链 NoDrop=0，第 2 节的"地狱 59% 是低阶底材"在任何 `/players` 下都成立
- **不改变物品 ilvl**（ilvl 只看怪物等级）
- **不增加怪物数量**（D2 不加怪物密度）

### 7.4 代价

| | /players 1 | /players 8 |
|---|---|---|
| 怪物 HP | 1× | **4.5×**（每多一人 +50%） |
| 经验 | 1× | **4.5×** |
| 掉落数量 | 1× | 1.45~2.63×（见上） |
| 怪物伤害 | 1× | 1×（不变） |

所以 `/players 8` 是**练级和刷箱子的工具，不是刷装备的工具**——
除非你的 build 清场速度几乎不随怪物血量下降（范围伤害、爆发高）。

### 7.5 对本项目的含义

我们的补丁没有动任何掉落表，所以第 2 节的底材分布结论在任意 `/players` 下都成立。
但**难度侧**要考虑：免疫封顶后"能破"了，可 `/players 8` 下怪有 4.5 倍 HP，
"能破"不等于"打得动"。

→ 见 `docs/p3-design.md` 的待定项：**平衡假设用哪个 `/players`？**
